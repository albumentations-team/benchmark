# R10: калибровка Elastic

R10 сравнивает деформации после crop до 224×224. В этой матрице у них
сопоставимая сила (около 0,74 px RMS) и масштаб (около 10 px).
Параметры закреплены в [каталоге рецептов](../catalog/recipes/rgb.yaml).

AlbumentationsX 2.6.1 строит поле по кубическим сплайнам на сетке контрольных
точек. Прежний AX 2.4.2 сглаживал шум гауссовым фильтром. TorchVision и Kornia
по-прежнему сглаживают шум, но по-разному переводят `alpha` в пиксели. При старых
`alpha=50`, `sigma=5` RMS поля был 0,91 px у AX 2.4.2, 1,15 px у TorchVision
и 258 px у Kornia. Новый AX с сеткой 29×29 ограничивает допустимую амплитуду
для сохранения топологии, поэтому общую силу снизили, сохранив масштаб.

| Реализация | Параметры | RMS, px | Масштаб, px |
| --- | --- | ---: | ---: |
| AX 2.6.1 | Сетка 29×29, `displacement_range=(0.0097, 0.0097)` | 0,745 | 10,12 |
| TorchVision 0.29.2 | `alpha=32`, `sigma=5` | 0,738 | 9,88 |
| Kornia 0.9.0 | `alpha=32/224`, `sigma=5` на обеих осях | 0,738 | 9,88 |

Значения проверены на CPU с PyTorch 2.15.0, на 24 полях с seeds 500–523.
Для AX использовали его генератор коэффициентов и карты сэмплирования. Для
TorchVision взяли поле из `ElasticTransform.make_params`, для Kornia — разность
между сеткой перед `grid_sample` и сеткой без смещения. Нормализованные
координаты TorchVision и Kornia умножили на 112, чтобы получить пиксели.

Из каждой карты брали центральные 176×176 пикселей. RMS — корень из среднего
квадрата длины вектора смещения. Масштаб — первый лаг, где средняя по обеим
осям автокорреляция поля падает ниже `1/e`, с линейной интерполяцией между
целыми лагами. Для расчёта автокорреляции из каждого поля вычли среднее по
его пространственным координатам. Совпадение этих двух величин не означает
одинаковые поля, граничные эффекты или пиксели. Скорость и память измеряются
отдельно от калибровки, одним проходом на L4 по production-контракту.
