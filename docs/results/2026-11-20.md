# RGB benchmark changes on 20 November 2026

The new L4 run uses 49,999 non-CMYK ImageNet validation JPEGs and a window of 30 warm-up plus 100 timed batches. The previous report used 10,000 JPEGs and a window of one warm-up plus 32 timed batches. Recipe parameters, adapters, and some package versions also changed. The throughput differences reflect those combined changes. [Previous report](https://github.com/albumentations-team/benchmark/blob/913da29/docs/generated/results.json) · [New report](../generated/results.json)

Across the 413 pairs with the same implementation and recipe name, the geometric mean of new-to-old throughput ratios was lower for every path. Each pair uses the median across the available seeds for its path and report. The new TorchVision GPU estimate uses six seeds. Matching ignores the older `+Normalize+ToTensor` suffix. The renamed channel-swap recipe and the separate grayscale Colorize workload are outside this comparison.

DALI's ColorJitter and ColorJiggle gained 39.7% and 42.7% in images/s. The DALI version and those recipes' factor ranges stayed the same, and the adapter now selects the operation at each of four steps instead of building a branch for every permutation. Kornia GPU's MedianBlur gained 72.6%, with a change from a fixed 5×5 window to a per-image choice of 3×3 or 5×5.
